# Changelog

All notable changes to this plugin are recorded here.

## 1.0.1

- Added `gemini-extension.json` so the repository installs as a Gemini CLI extension.

## 1.0.0: initial release

- Added the `hitpay` MCP server pointing at `https://mcp.hit-pay.com/`.
- Auth uses OAuth with your HitPay login. There is no API key or client ID to configure.
